# Assets

`cover-placeholder.png` is the supplied concept artwork. Its wording and editor names are placeholders; replace it before publication. It is shown on the web opening page and labelled accordingly. It is not presented as a final PDF cover.

`imported/media/` contains the source manuscript's 70 embedded image files. Original TIFF and EMF assets are retained; browser-compatible PNG derivatives are used in the reading sources. Check legibility, alt text and permissions with the chapter authors.

`review-reference.docx` controls Word review formatting. It is a formatting dependency, not a rendered manuscript output.
