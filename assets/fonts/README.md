# OpenDyslexic web fonts

Unmodified Latin regular (400) and bold (700) WOFF2 files distributed by
Fontsource at https://cdn.jsdelivr.net/npm/@fontsource/opendyslexic/files/.
Downloaded 23 November 2026. Copyright Abbie Gonzalez; SIL Open Font License
1.1 with Reserved Font Name OpenDyslexic. See OFL.txt.

The font is an optional reading preference. The book uses its ordinary typeface
until the reader enables it; the preference is stored locally in the browser.
