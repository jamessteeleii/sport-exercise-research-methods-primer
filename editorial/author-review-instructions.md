# Author review of Research Methods in Sport and Exercise Science

Please review your chapter's editorial changes and comments, suggest any further edits, and check the clean reading proofs. These proofs show the proposed appearance of the HTML and PDF editions. This is the final contributing-author review round before the editors integrate responses and prepare the next proofs; author approval is still pending.

The live reading proofs are available at:

- HTML book: <https://sportexercisemethods.org/>
- Whole-book PDF: <https://sportexercisemethods.org/research-methods-ses.pdf>

Use the dated PDF supplied with this review round when commenting on a fixed version. The live website may change as responses are integrated. The cover is a placeholder and publication identifiers and rights information will be completed before publication.

## Review the Word file

1. Save a working copy of the chapter supplied to you. Add your surname and return date to its filename, keeping the chapter number and review-round identifier.
2. Open it in desktop Microsoft Word where possible. Select **Review > All Markup**, open the comments pane, and ensure **Track Changes** is on. The historical chapter files have markup display and tracking enabled, but Word's own display preferences can override what is visible. Coloured insertions/deletions and comments are the review record; existing text highlights may also be present.
3. Consider the editors' tracked changes individually. You may accept or reject them in your returned working copy, adding a comment where your decision needs explanation. Reply to outstanding editorial comments and retain those threads with your response. Please avoid an indiscriminate Accept All before reviewing the edits.
4. Make additional edits with Track Changes on and use comments for questions, alternatives or instructions that cannot be represented by a simple text edit. Preserve citation fields and leave a comment with full reference details if a citation needs changing.
5. Coordinate a single response across the chapter's coauthors where practical. If you return separate files, identify whose response each contains and flag any conflicting suggestions.

Chapter one is an exception: `01-foundations-current-proof.docx` reflects the separately reconciled author revision and is the file to proofread and edit. `01-foundations-historical-review.docx` preserves earlier editorial markup for context; it must not replace the current text. Its previously reconciled changes do not need to be reviewed again.

Chapters two to nine retain the reviewed Word manuscript's editorial history. The clean HTML/PDF also include subsequent formatting, reference processing and agreed corrections. Their section numbering, reference presentation and layout can therefore differ from Word. Please flag any substantive discrepancy you find; use the clean proofs to check the proposed reading edition and Word to record review decisions.

## Check the reading proofs

Check your chapter in both HTML and PDF, paying particular attention to:

- Author names, author order and affiliations.
- Scientific content, terminology, quotations, references and any remaining placeholders.
- Tables, figures, captions, equations, symbols and figure or table numbering.
- Footnotes, references and links, including links to other chapters and external resources.
- Figure, quotation and other third-party material permissions or acknowledgements.

HTML collects footnotes at the end of each chapter before References. PDF uses page-level footnotes and chapter-level reference lists. These differences are intentional.

You may annotate the supplied PDF instead of, or alongside, editing Word. Return the annotated PDF rather than replacing its text. Identify the chapter, printed page number, heading and a short quotation for each correction; if using the PDF viewer's page count, say so. Please also respond to the existing Word comments and tracked edits, either in Word or in an accompanying response list, so that each editorial query has a clear decision.

## Return your response

Return your revised chapter Word file and/or annotated PDF to the editors through the same correspondence used to send this package. Include any accompanying response list and confirm:

1. Which dated review package and files you reviewed.
2. Whether the chapter's coauthors have agreed the response.
3. Whether you approve the proposed chapter subject to the corrections supplied, or whether questions remain outstanding.
4. Whether names, affiliations and permissions information are correct, identifying anything still pending.

The editors will deliberately transfer agreed changes into the maintained book sources and issue updated proofs where needed. Please review those before final sign-off if substantive changes have been made. A response to this round is not automatically recorded as approval of a later version.
